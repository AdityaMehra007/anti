## 1. Legal Capability Replication Matrix

Every capability cataloged in the Omniverse is assigned a legal classification level that dictates how it may be utilized, adapted, or reimplemented:

| Level | Classification | Action Policy | Example Technologies |
|:---:|:---|:---|:---|
| **LEVEL A** | Permissive Open Source (MIT, Apache 2.0, BSD) | Direct integration, enhancement, attribution per license terms. | SQLite, FastAPI, Pytest, LangChain primitives, PyTorch. |
| **LEVEL B** | Publicly Documented Standard / Protocol | Clean-room independent reimplementation based on public specs. | Incoterms 2020 rules, CBAM XML standards, REST/OpenAPI, MCP protocol. |
| **LEVEL C** | Commercial API / Authorized SaaS | Integration strictly via authorized developer API keys and subscriptions. | Firecrawl API, GitHub API, Google Gemini API, Claude API. |
| **LEVEL D** | User-Provided Private Credentials | Operation restricted to the explicit sandbox boundaries of the user. | User-owned LinkedIn session cookies, private DB credentials. |
| **LEVEL E** | Proprietary Commercial Internal Code | **Strictly prohibited from copying.** Reimplement functional abstraction independently. | BlackRock Aladdin models, Bloomberg terminal internals, Salesforce Apex core. |
| **LEVEL F** | Classified / Restricted / Regulated Data | **Zero collection/processing** without explicit legal authorization. | Defense export ITAR data, non-consensual PII, classified materials. |
