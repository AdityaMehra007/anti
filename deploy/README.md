# 🚀 ANTIGRAVITY PLATFORMS — DEPLOYMENT & HOSTING GUIDE

This directory (`e:\anti\deploy`) contains the unified web portal and landing pages ready for instant, zero-cost internet deployment.

---

## 🌐 1. Deploy to GitHub Pages (Free)
1. In your GitHub repository settings, go to **Settings ➔ Pages**.
2. Under **Build and deployment ➔ Source**, select **Deploy from a branch**.
3. Choose your branch (e.g. `main`) and folder `/deploy` (or root `/` if deployed from a dedicated gh-pages branch).
4. Click **Save**. Your site will be live at: `https://<your-username>.github.io/<repo-name>/`

---

## ⚡ 2. Deploy to Vercel (1-Click)
1. Install Vercel CLI: `npm i -g vercel` (or link your GitHub repo at [vercel.com](https://vercel.com)).
2. In PowerShell, run:
   ```powershell
   cd e:\anti\deploy
   vercel --prod
   ```
3. Your site is instantly assigned a global SSL domain (e.g. `https://antigravity-platforms.vercel.app`).
