# Database & File Schema Reference
**Directory:** `docs/database/`  

## Primary Ledgers
1. `job_applications.csv`: Active application tracking sheet (`Date`, `Company Name`, `Role Title`, `Location/Remote`, `Job Board / Portal`, `Application URL`, `Status`, `Follow-Up Date`, `Contact Person`, `Notes`).
2. `data/jobs_master.csv`: 58 deduplicated verified open requisitions in Bengaluru.
3. `data/referral_targets.csv`: Recruiter and alumni outreach targets.
4. `system_memory_store.json`: Persistent system memory and learned networking patterns.
5. `DATA_DICTIONARY.md`: 9,223 LinkedIn connection taxonomy.
