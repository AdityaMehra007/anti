# University Curriculum Roadmap: Database Engine & Storage Systems Architect

> **Role Archetype**: `database-storage-architect`  
> **Overview**: Design high-performance relational storage managers, B-Tree and LSM indexing engines, buffer pool managers, vector databases, and distributed query execution.  
> **Total Curated Courses**: 16 courses across 4 progressive tiers.
