# University Curriculum Roadmap: Systems & Distributed Infrastructure Architect

> **Role Archetype**: `systems-distributed-engineer`  
> **Overview**: Architect planetary-scale cloud systems, low-latency operating system kernels, distributed consensus protocols (Raft/Paxos), and high-throughput networking.  
> **Total Curated Courses**: 16 courses across 4 progressive tiers.
