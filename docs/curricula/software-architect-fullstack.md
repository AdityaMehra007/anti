# University Curriculum Roadmap: Principal Software Architect & Full-Stack Engineer

> **Role Archetype**: `software-architect-fullstack`  
> **Overview**: Design modular, resilient enterprise software architectures, API contracts, high-load web systems, compiler optimizations, and scalable data layers.  
> **Total Curated Courses**: 15 courses across 4 progressive tiers.

**Target Level**: `Introductory (L1)`  
**Key Competencies**:
- Polymorphism & data abstraction
- Testing & debugging harnesses
- Data structuring
