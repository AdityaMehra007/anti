# University Curriculum Roadmap: Information Security & Cryptography Engineer

> **Role Archetype**: `security-cryptography-engineer`  
> **Overview**: Protect systems against adversarial vectors, engineer zero-knowledge proofs, audit protocol cryptographic invariants, and harden operating system seams.  
> **Total Curated Courses**: 16 courses across 4 progressive tiers.

---
