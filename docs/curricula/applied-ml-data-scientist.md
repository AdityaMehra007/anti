# University Curriculum Roadmap: Applied Machine Learning & Data Scientist

> **Role Archetype**: `applied-ml-data-scientist`  
> **Overview**: Build production predictive pipelines, statistical hypothesis tests, time-series forecasting, and scalable data mining engines across massive datasets.  
> **Total Curated Courses**: 16 courses across 4 progressive tiers.

---

## Tier 1: Python for Data Science & Linear Algebra
**Target Level**: `Introductory (L1)`  
**Key Competencies**:
- Numpy/Pandas data vectorization
- Matrix operations
- Exploratory data analysis
