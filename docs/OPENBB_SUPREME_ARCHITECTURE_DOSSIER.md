## 1. Executive Summary & Capabilities Ledger

The **Open Data Platform (ODP v5.0.0)** by OpenBB is an enterprise-grade financial data aggregation and analytics platform designed for quant researchers, asset managers, data engineers, and AI agents. It decouples high-throughput financial data sourcing from application logic through a modular, plugin-driven architecture consisting of:

1. **Python Core SDK (`openbb`)**:
   - Monolithic static interface compiled dynamically from 36 installed packages.
   - 90 routers covering 888 unique financial API endpoints.
   - 19 active data providers offering real-time and historical coverage across equities, options, futures, fixed income, macroeconomics, government debt, energy, and foreign exchange.
2. **REST API Backend (`openbb-platform-api`)**:
   - Ultra-fast asynchronous FastAPI server running on port `6900`.
   - Native integration with the OpenBB Workspace (`widgets.json`, `apps.json`, `agents.json`).
   - Dynamic CORS, security headers, and pluggable HTTP middleware pipeline.
3. **Model Context Protocol Server (`openbb-mcp-server`)**:
   - FastMCP architecture supporting `streamable-http`, `sse`, and `stdio` transports on port `8001`.
   - Tool discovery protocol (`available_categories`, `available_tools`, `search_tools`, `call_tool`) allowing AI agents (Claude, Gemini, Cursor, Copilot, Antigravity) to query financial markets autonomously.
   - Built-in Agent Skills directory provider supporting Claude Skills, Codex Skills, Cursor Skills, and Gemini Skills.
4. **Interactive Command-Line Terminal (`openbb-cli`)**:
   - High-performance command dispatcher with prompt-toolkit auto-completion and Rich formatting.
   - Spec-driven proxy compiler (`openbb --generate-spec`) and automated extension scaffolding (`openbb --generate-extension`).
5. **Cross-Platform Desktop Client (`desktop`)**:
   - High-fidelity React 18 + TypeScript financial desktop workbench bundled with Vite 7.3.7.
   - Powered by Tauri v2 with native Rust system bridge.

## 4. MCP Server & AI Agent Interoperability

The OpenBB FastMCP server (`openbb-mcp.exe`) connects AI reasoning engines directly to financial data feeds.

### Key Capabilities:
1. **Dynamic Tool Catalog**:
   - `available_categories`: Returns list of financial namespaces (`equity`, `economy`, `crypto`, `derivatives`, `fixedincome`, etc.).
   - `available_tools(category)`: Lists all tools available under a given domain.
   - `search_tools(query)`: Semantic and keyword search across all 888 tool descriptions.
   - `call_tool(tool_name, arguments)`: Dispatches the underlying query with automatic JSON schema validation.
2. **Pre-Built Agent Skills**:
   Bundled directly with standard operating instructions for LLMs:
   - `build_workspace_app`: Guidelines for authoring custom OpenBB Workspace widgets.
   - `configure_mcp_server`: Dynamic config and auth hook documentation.
   - `develop_extension`: Complete blueprint for writing new data providers or routers.
   - `use_openbb_cli`: Instructions for autonomous CLI invocation.
   - `work_with_server`: Direct REST and SSE protocol documentation.

### Transport Modes:
```powershell
# SSE / HTTP Streaming (recommended for multi-agent network architectures):
openbb-mcp --transport streamable-http --host 127.0.0.1 --port 8001

# Standard I/O (for local agents, Claude Desktop, Cursor, and Antigravity stdio config):
openbb-mcp --transport stdio
```
