Model Context Protocol (MCP) Execution Lifecycle

MCP standardizes communication between host LLM applications (clients) and external data/tool providers (servers) via standardized JSON-RPC 2.0 messages over standard I/O (stdio) or Server-Sent Events (SSE).

1

Client Handshake & Capability Negotiation

The host client boots the child process and sends an initialize request with protocol version, capabilities, and client metadata.

{ "jsonrpc": "2.0", "id": 1, "method": "initialize", "params": { "protocolVersion": "2024-11-05", "capabilities": {}, "clientInfo": { "name": "claude-code", "version": "1.0.0" } } }
2

Server Capability Affirmation

The server replies with supported protocol versions, feature capabilities (tools, resources, prompts, logging), and server identification.

{ "jsonrpc": "2.0", "id": 1, "result": { "protocolVersion": "2024-11-05", "capabilities": { "tools": {} }, "serverInfo": { "name": "plane-mcp-server", "version": "1.0.0" } } }
3

Dynamic Tool Discovery

The client calls tools/list to fetch all registered executable tools along with their JSON Schema parameters.

{ "jsonrpc": "2.0", "id": 2, "method": "tools/list", "params": {} }
4

Tool Execution Dispatch

When the model decides to invoke a tool, the client dispatches tools/call with validated structured arguments.

{ "jsonrpc": "2.0", "id": 3, "method": "tools/call", "params": { "name": "plane_create_issue", "arguments": { "project_id": "OMEGA-CORE", "name": "Deploy Windmill DAG", "priority": "high" } } }
5

Structured Context Ingestion

The server completes execution and returns text or embedded resources back into the model's active context window.

{ "jsonrpc": "2.0", "id": 3, "result": { "content": [{ "type": "text", "text": "{\"status\": \"success\", \"issue_id\": \"ISS-9821\"}" }] } }

Automated Server Health & Protocol Test Bench

You can audit all 24 MCP servers locally via CLI to verify process startup, handshake latency, and tool schema validity.

python mcp_cli.py test

# 2. Test a specific sovereign server (e.g. Plane, Windmill, PowerShell):
python mcp_cli.py test plane

# 3. Launch single composite multiplexer (proxying all 260 tools over stdio):
