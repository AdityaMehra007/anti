# SKILL: Client Fulfillment Automation

## Objective
Deliver 15+ qualified meetings for each onboarded client within 45 days with <60 minutes of setup time per account.

## Execution Directives
1. **Onboarding Sprint (Day 1)**:
   - Provide the single-page onboarding questionnaire (ICP parameters, exclusions, primary value proposition).
2. **Setup Automation (Days 2–3)**:
   - Configure sending inboxes and automated warmup pools.
   - Run initial scrape of 1,000 verified decision-maker emails.
   - Run AI icebreaker personalization script.
3. **Launch & Routing (Day 4+)**:
   - Connect real-time webhook routing to client's Slack / email / calendar.
   - Deliver weekly pipeline performance report every Monday morning.
