🏛️ The Four Inviolable Architectural Principles
1. Local-First

Everything runs on your machine against your files. No account required, no server in the loop for the core engine.

2. AI-Agnostic

Logic lives in Markdown prompt files under modes/, executed by whatever AI coding CLI you use (Claude Code, Codex, Gemini, Antigravity) or standalone Node/Python evaluators.

3. Human-in-the-Loop

The tool evaluates, discovers, and prepares; the human reviews and clicks. It never submits applications on your behalf.

4. Files are Canonical — Databases are Derived

Human-readable, git-diffable files (data/applications.md, reports/) are the permanent truth. SQLite is only a fast transient query index.

🛡️ Data Contract & Boundary Policy
DATA_CONTRACT.md

The single most critical rule: System files and User files are strictly separated. The updater (update-system.mjs) NEVER touches your user layer.

Layer Paths Lifecycle
System Layer modes/, providers/, templates/, *.mjs, lib/ Versioned & safely updated via upstream pull
