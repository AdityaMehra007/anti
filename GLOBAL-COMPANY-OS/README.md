# GLOBAL COMPANY OS: Master Repository Architecture

Welcome to the **GLOBAL COMPANY OS**, the central autonomous command center for building an elite, AI-leveraged, top-1% global enterprise from Bengaluru, India.

---

## Operating Hierarchy & Security Tiers

All agents, scripts, and automations operate under **Least Privilege**:
1. **READ**: Inspect documents, state files, and logs.
2. **ANALYZE**: Synthesize data, run simulations, compute metrics.
3. **DRAFT**: Generate code, proposals, templates, and reports into staging.
4. **RECOMMEND**: Present ranked options with confidence and cost-benefit analysis.
5. **EXECUTE**: Commit changes, trigger automations, or ship tested code. High-risk operations (financial transfers, legal filings, production credentials) require explicit **Human Founder Approval**.
